# QR Codes

There are two QR codes. One is a poster that points guests at the app. The other is shown by a worker
to set up a phone for a guest they added by hand.

## The poster

A printable page that opens the app when scanned.

The web address under the code is the one this document was made from; the printed poster shows the
live site's. The Back and Print buttons at the top do not appear on paper.
