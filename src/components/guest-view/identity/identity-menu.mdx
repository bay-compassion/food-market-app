# Identity Menu

What a guest can do with the details saved on their phone. The menu is on the "Recognized on this
device" card. Its first item, Opt Out, is only available to a guest who has agreed to text messages.

## The menu

## Show device ID

The ID identifies this phone to the market. A guest may be asked to read it out to a member of staff.
The ID shown here is made up.

<Still id="device-id" alt="A dialog titled Device ID, showing a made-up ID and a Copy button" />

## Forget my information

Removes the saved name, phone number, and device ID from this phone. The guest is asked to confirm,
since it cannot be undone.
