# Text Updates

A guest the app already knows can agree to text messages about their visit. The button on the
"Recognized on this device" card opens the agreement, and the card shows which of these states the
setting is in.

## Asked to agree

The agreement is in a dialog. The button to enable text updates stays unavailable until the box is
ticked.

<Still
	id="text-updates"
	alt="The text message updates dialog, with an unticked agreement and a disabled Enable button"
/>

## Agreed

Once the box is ticked, the button becomes available.

<Still
	id="text-updates-agreed"
	alt="The dialog with the agreement ticked and the Enable text updates button available"
/>

## Texted STOP earlier

A guest who has texted STOP to the market's number can only start again by texting START. The dialog
explains this and offers to open a text with START ready to send.

	id="text-updates-opted-out"
