# Text Messages

These examples show messages sent to guests who enabled text updates. Phone alerts use the same
titles and generally the same wording.

The shaded parts show the sender name, `The Bay Compassion:`, and the opt-out instruction currently
sent at the end of each text: `Reply STOP to unsubscribe`. The current messages leave both in English.
Only `STOP` must remain in English; the surrounding instruction can be translated. See the decision
in the Introduction.

## Selected for the queue

This is the only text that includes the guest's place in line. The number is their position when the
text is sent. The app continues to update their position as the line moves; it does not send another
text for each change.
