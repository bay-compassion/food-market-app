# Guest States

Guests move through a distinct set of states when using the app.

<Mermaid
	chart={`
	flowchart TD
		Start([Market Closed])
		MarketOpens[Market Opens]
		Lottery[Lottery Drawn]
		MarketCloses([Market Closes])

    	Start --> |On schedule or manually| MarketOpens
    	MarketOpens --> |Registered within window| Registered
    	MarketOpens --> |Missed window| MarketCloses

    	Registered --> Lottery
    	RegistrationCloses[Registration Closes] --> Cancelled

    	Lottery --> |Selected| Waiting
    	Lottery --> |Cancels| Cancelled
    	Lottery --> |Not Selected| MarketCloses

    	Waiting --> Called --> Served
    	Served --> MarketCloses

    	Waiting --> |Cancels| Cancelled
    	Called --> |Cancels| Cancelled

    	Cancelled --> MarketCloses
    	MarketCloses --> End([↺ Restart])
    `}

/>

## Status Cards

The following cards are used to represent the status of a guest.

### Market Closed

This is the state for most of the week, from the time when the previous market event has MarketClosesed until registration opens for the next market event.

See the forms documentation for more information on the guest registration form.
